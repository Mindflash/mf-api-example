Use this endpoint to add user group information.

Name Type Optional Value
responseFormat Query String YES Format the response. Possible values are array (default) and json.
groupName Body NO Name of the group as a string. This handler does not validate a maximum length. 
{
  "groupName": "{a group name}"
}
Note When posting json data in the body of the request, the Content-Type must be set to application/json.

Examples

Example: Add User Group to an organization 
POST https://api.mindflash.com/api/v3/group

{
  "groupName" : "a group name"
}

Response: 200
[12345, null, "a group name", null, 1662730986]
Example: Add a group and request a JSON response 
POST https://api.mindflash.com/api/v3/group?responseFormat=json

{
  "groupName": "a group name"
}

Response: 200
{
  "id": 1662730986,
  "accountId": 12345,
  "name": "a group name"
}
