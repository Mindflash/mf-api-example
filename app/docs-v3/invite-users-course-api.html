Use this endpoint to invite multiple users to a specific course.

Name Type Optional Value
:courseId URL NO The Mindflash ID of the course to invite the users to. 
{
  "userIds": [],
  "clientDatestamp": "2013-07-17",
  "required": false
}
Note When posting json data in the body of the request, the Content-Type must be set to application/json.
Field Type Optional Notes
userIds Body NO An array of Mindflash user IDs to invite to the course.
clientDatestamp Body YES Defaults to the current date if omitted. All dates must be in the format YYYY-MM-DD.
required Body YES Set true to make the course required for the users. Default is false.
invitedBy Body YES Mindflash user ID recorded as the inviter. If omitted, the API's default inviter ID is used.
inviteType Body YES Initial course status for the invited users. Supported values: 116000050 (Invited, the default) or 116000700 (Pending). A Pending invitation does not set a completion deadline and does not start the normal invitation processing. The API only checks that the value is a number, so do not send other codes.

Examples

Example: Invite 3 users to a course. 
POST https://api.mindflash.com/api/v3/course/1662438386/invite

{
  "userIds": [4567, 7898, 9988],
  "clientDatestamp": "2013-07-17",
  "required" : false,
  "invitedBy": 1662427377
}
					
Response: 200
