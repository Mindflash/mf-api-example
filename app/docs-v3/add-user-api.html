Use this endpoint to add users to the Trakstar Learn system. The user information supplied must contain the basic information, but can optionally include group information and course enrollment information.
Note: Between 1 and 200 users may be submitted per API call. 

{
  "users": [
    {
      "firstName": "",
      "lastName": "",
      "email": "",
      "username": "",
      "permissions": 169000100,
      "customField0": "",
      "customField1": "",
      "customField2": "",
      "customField3": "",
      "customField4": "",
      "customField5": "",
      "customField6": "",
      "customField7": "",
      "customField8": "",
      "customField9": ""
    }
  ],
  "requiredCourseIds": [],
  "courseIds": [],
  "groupIds": [],
  "groupRestrictionIds": [],
  "clientDatestamp": "",
  "batchId" : 1,
  "mode": "import"
}
Note When posting json data in the body of the request, the Content-Type must be set to application/json.
Field Optional Notes
users NO A list of all users information to be added to the Trakstar Learn system.
Field Optional Max Length Notes
firstName NO 35 Users first name.
lastName NO 35 Users last name.
email YES* 254 Users email address.
username YES* 254 Unique username for user.
permissions YES N/A One of:
169000100 — Trainee (Default)
169000200 — Manager
169000300 — Trainer
169000400 — Administrator
169000500 — Reporter
169000600 — Team Lead
customField0,
customField1,
...
customField9		 YES 200 Custom fields for the user. Fields are named customField0 through customField9 (10 fields total). Supply only the fields you wish to set.
yammerId YES N/A Yammer ID of user.
password YES 35 A login password, 8 to 35 characters, containing an uppercase letter, lowercase letter, number, and symbol.
forcePasswordChange YES N/A Boolean, defaults to false. When true, the user is prompted to choose a new password the first time they log in with the supplied password. Requires a password in the same user entry. Applies to both new and existing users. When omitted or false, the supplied password follows the account's normal password-expiration policy.
* Note: At least one of email or username must be supplied. Both may be supplied.
requiredCourseIds YES A list of Trakstar Learn course IDs to enroll the users in. All users will be enrolled in these courses with the required option enabled.
courseIds YES A list of Trakstar Learn course IDs to enroll the users in. All users will be enrolled in these courses with the required option disabled.
groupIds YES A list of Trakstar Learn group IDs to place the users in. All users will be placed into these groups.
groupRestrictionIds YES A list of group IDs restricting which existing users may be updated by the import.
clientDatestamp YES Defaults to the current date if omitted. All dates must be in the format YYYY-MM-DD.
batchId YES An identifier for this specific API call. If omitted, the handler uses a default value. Upon success, the value is returned in the response.
mode YES Defaults to import, which updates existing users matched by email or username. With any other value, the request fails if a submitted user matches an existing user by email or username.

Examples

Example: Add 2 trainees and enroll in 3 courses, 1 which is required. 
POST https://api.mindflash.com/api/v3/user

{
  "users": [
    {
      "firstName": "Tom",
      "lastName": "Jones",
      "email": "tjones@yourorg.com"
    },
    {
      "firstName": "Rumple",
      "lastName": "Stilskin",
      "email": "rumple@yourorg.com"
    }
  ],
  "requiredCourseIds": [ 1234 ],
  "courseIds": [ 6789, 6543 ],
  "groupIds": [],
  "groupRestrictionIds": [],
  "clientDatestamp": "2013-07-17",
  "batchId" : 122
}
					
Response: 200
{
  "batchId": 122
}
Example: Add a trainee with an initial password they must change at first login. 
POST https://api.mindflash.com/api/v3/user

{
  "users": [
    {
      "firstName": "Tom",
      "lastName": "Jones",
      "email": "tjones@yourorg.com",
      "password": "Initial-Passw0rd!",
      "forcePasswordChange": true
    }
  ],
  "courseIds": [ 6789 ],
  "clientDatestamp": "2013-07-17",
  "batchId" : 123
}
					
Response: 200
{
  "batchId": 123,
  "added": [
    { "id": 98765, "email": "tjones@yourorg.com" }
  ],
  "updated": []
}
