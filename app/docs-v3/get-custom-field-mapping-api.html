Use this endpoint to retrieve the account's mapping from the ten API custom-field keys to configured user-field names. Each value is the configured name or null if that field is not configured. These keys correspond to customField0 through customField9 used when adding or editing a user. User responses expose configured names for custom fields when the account's custom-field mapping is applied.

Examples

Example: Get custom-field mappings 
GET https://api.mindflash.com/api/v3/customFieldMapping
Response: 200
