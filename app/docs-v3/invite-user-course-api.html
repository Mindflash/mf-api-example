Use this endpoint to invite a specific user to a specific course. The alias POST /api/v3/user/:userId/course/:courseId/invite is also supported.

Name Type Optional Value
:courseId URL NO The Mindflash ID of the course to invite the user to.
:userId URL NO The Mindflash ID of the user to invite to the course. 
{
  "clientDatestamp": "2013-07-17",
  "required": false
}
Note When posting json data in the body of the request, the Content-Type must be set to application/json.
Field Type Optional Notes
clientDatestamp Body YES Defaults to the current date if omitted. All dates must be in the format YYYY-MM-DD.
required Body YES Set true to make the course required for the user. Defaults to false if omitted.
invitedBy Body YES Mindflash user ID recorded as the inviter. If omitted, the API's default inviter ID is used.
inviteType Body YES Numeric invitation type code. The handler does not define a public list of values.
inviteDate Body YES Invitation date (ISO 8601 date or date/time).

Examples

Example: Invite a user to a course. 
POST https://api.mindflash.com/api/v3/course/1662438386/user/1662427377/invite

{
  "clientDatestamp": "2013-07-17",
  "required" : false,
  "invitedBy": 1662427377,
  "inviteDate": "2013-07-17T18:47:52.000Z"
}
Response: 200
