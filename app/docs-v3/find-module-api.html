Use this endpoint to find integration modules by matching configured custom-field values. Provide at least one of customField0 or customField1; each supplied value is a string of at most 256 characters. Using customField0 requires the account's WebinarIntegration feature toggle. A customField1-only lookup does not require that toggle.

Name Type Optional Value
customField0 Querystring YES* String, maximum 256 characters. Using this field requires the WebinarIntegration feature toggle.
customField1 Querystring YES* String, maximum 256 characters.
* At least one of customField0 or customField1 must be provided.

Examples

Example: Find a module by custom-field values 
GET https://api.mindflash.com/api/v3/integration/module?customField0=event-123&customField1=west
Response: 200
{
  "modules": [
    {
      "id": 12345,
      "name": "Example module"
    }
  ]
}
Response: 400
{
  "message": "The WebinarIntegration feature toggle must be on and either the customField0 and/or customField1 parameter(s) must be provided."
}
Response: 404
{
  "message": "not found"
}
