Use this endpoint to mark an In-Person module complete for one or more users. The module must exist and be an In-Person module. Each successful item completes the module for the matched user and course; item-level failures are returned as warnings. A missing module returns 404 with code module_not_found; an invalid module type returns 400 with code cModule_type_invalid. Missing identifiers use code user_identifier_required, a future completion date uses cModule_invalid_completion_date, and a required score uses cModule_score_required. 

{
  "completions": [
    {
      "userId": 456,
      "courseId": 123,
      "completionDate": "2020-01-01T12:00:00.000Z",
      "score": 100
    }
  ]
}
Note When posting json data in the body of the request, the Content-Type must be set to application/json.
Field Optional Notes
completions NO Required array with at most 100 completion items.
userId YES* Numeric Mindflash user ID.
email YES* User email address.
username YES* User name.
courseId YES Numeric course ID. If omitted, matching module assignments are considered across courses.
completionDate YES ISO-8601 date/time that is not in the future. Defaults to the current time.
score YES Number from 0 through 100. Required when the module has a passing score enabled. If omitted when only quiz scores matter, the handler defaults the score to 100.
* Each completion item must include at least one of userId, email, or username.
Name Type Optional Value
:moduleId URL NO The integration module ID.

Examples

Example: Complete a module for a user 
POST https://api.mindflash.com/api/v3/integration/module/9876/complete

{
  "completions": [
    {
      "userId": 456,
      "courseId": 123,
      "completionDate": "2020-01-01T12:00:00.000Z",
      "score": 100
    }
  ]
}
Response: 200
{
  "completions": [
    {
      "userId": 456,
      "courseId": 123,
      "cModuleId": 9876
    }
  ],
  "warnings": []
}
Response: 200
{
  "completions": [],
  "warnings": [
    {
      "details": {
        "userId": 456,
        "courseId": 123
      },
      "status": "failed",
      "message": "User is not assigned to the module"
    }
  ]
}
