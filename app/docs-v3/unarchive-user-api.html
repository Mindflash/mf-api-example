Use this endpoint to unarchive a user. Unarchiving restores a user's ability to take courses and login to the Mindflash site. The target user must currently be archived, and the account must have an available user seat.

Name Type Optional Value
:userId URL NO The Mindflash ID of the user to unarchive.

Examples

Example: Unarchive a user. 
POST https://api.mindflash.com/api/v3/user/333/unarchive

					
Response: 200
Example: User not found 
POST https://api.mindflash.com/api/v3/user/999999/unarchive

					
Response: 404
{
  "code": "user_not_found",
  "message": "User not found: 999999.",
  "type": "unarchive_user"
}
Example: User is not archived 
POST https://api.mindflash.com/api/v3/user/333/unarchive

					
Response: 400
{
  "code": "user_not_archived",
  "message": "You cannot unarchive a user who is not archived: Jane Doe.",
  "type": "unarchive_user"
}
