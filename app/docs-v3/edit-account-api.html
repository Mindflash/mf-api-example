Use this endpoint to update account settings. Only name, description, disabled, status, and statusModified are accepted in the request body. Each setting is optional. Requests containing other keys return an errors entry with HTTP 200. 

{
  "name": "",
  "description": ""
}
Note When posting json data in the body of the request, the Content-Type must be set to application/json.
Field Optional Notes
name YES Account name.
description YES Account description.
disabled YES Account disabled setting.
status YES Account status value.
statusModified YES Timestamp associated with the account status.

Examples

Example: Update account settings 
POST https://api.mindflash.com/api/v3/account

{
  "name": "Example account",
  "description": "Account description"
}
Response: 200
{
  "errors": [],
  "warnings": [],
  "settings": {
    "name": "Example account",
    "description": "Account description",
    "disabled": false,
    "status": "account status value",
    "statusModified": "timestamp"
  }
}
Example: A disallowed key is reported in the response body 
POST https://api.mindflash.com/api/v3/account

{
  "unsupportedSetting": true
}
Response: 200
{
  "errors": ["Error: Keys are not allowed: unsupportedSetting"],
  "warnings": []
}
