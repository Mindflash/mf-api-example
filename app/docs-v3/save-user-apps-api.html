Use this endpoint to replace the app records associated with a user. Each request replaces all existing apps for that user with the apps in the request.

Name Type Optional Value
:userId URL NO The Mindflash user ID. 
{
  "consoleCustomerId": 123,
  "apps": [
    {
      "appType": "trakstar_learn"
    }
  ]
}
Note When posting json data in the body of the request, the Content-Type must be set to application/json.
Field Optional Notes
consoleCustomerId NO Required numeric customer ID.
apps NO Required array containing 1 through 10 app entries.
appType NO One of trakstar_console, trakstar_hire, trakstar_learn, or trakstar_perform.

Examples

Example: Save a user's app 
POST https://api.mindflash.com/api/v3/integration/user/456/app

{
  "consoleCustomerId": 123,
  "apps": [
    {
      "appType": "trakstar_learn"
    }
  ]
}
Response: 200
{
  "success": true
}
