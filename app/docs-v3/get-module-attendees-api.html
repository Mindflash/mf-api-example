Use this endpoint to get the active users attending an integration module. The response includes their associated course and module status. moduleStatus is one of Completed, Invited, Started, or MissedDeadline.

Name Type Optional Value
:moduleId URL NO The integration module ID.

Examples

Example: Get attendees for a module 
GET https://api.mindflash.com/api/v3/integration/module/12345/attendees
Response: 200
{
  "attendees": [
    {
      "courseId": 123,
      "userId": 456,
      "userEmail": "person@example.com",
      "userName": "Example Person",
      "moduleStatus": "Started"
    }
  ]
}
Response: 404
{
  "message": "module not found"
}
