Use this endpoint to add users to the Mindflash system. The user information supplied must contain the basic information, but can optionally include group information and course/series enrollment information.
Note: A maximum of 200 users may be added per api call. 

{
  "users": [
    {
      "firstName": "",
      "lastName": "",
      "email": ""
    }
  ],
  "requiredCourseIds": [],
  "courseIds": [],
  "seriesIds": [],
  "groupIds": [],
  "clientDatestamp": "",
  "batchId" : 1
}
Note When posting json data in the body of the request, the Content-Type must be set to application/json.
Field Optional Notes
users NO A list of all users information to be added to the Mindflash system.
Field Optional Max Length Notes
firstName NO 35 Users first name.
lastName NO 35 Users last name.
email YES* 254 Users email address.
username YES* 254 Unique username for user.
permissions YES N/A One of the following role names (case-insensitive):
administrator
manager
trainer
trainee (Default)
Numeric role values, or strings containing these values, are also accepted:
169000400 (administrator)
169000200 (manager)
169000300 (trainer)
169000100 (trainee)
0 (none)
169000500 (reporter)
169000600 (teamLead).
For new users, 0 defaults to trainee.
yammerId YES N/A Yammer ID of user.
password YES 35 A login password of at least 8 and at most 35 characters, containing an uppercase letter, a lowercase letter, a number and a symbol. Passwords allow the user to login via the Trakstar Learn website. A supplied password is subject to the account's password-expiry policy: it expires once the account's password lifetime elapses, and the user is then prompted to set a new password at their next login.
* Note: At least one of email or username must be supplied. Both may be supplied. When permissions explicitly specifies trainee (by name or numeric value), supplying username requires password. When permissions explicitly specifies a non-Trainee role other than 0, supplying both username and password also requires email.
requiredCourseIds YES A list of Mindflash course IDs to enroll the users in. All users will be enrolled in these courses with the required option enabled.
courseIds YES A list of Mindflash course IDs to enroll the users in. All users will be enrolled in these courses with the required option disabled.
seriesIds YES A list of Mindflash series IDs to enroll the users in. All users will be enrolled in these series.
groupIds YES A list of Mindflash group IDs to place the users in. All users will be placed into these groups.
clientDatestamp NO The current date. All dates must be in the format YYYY-MM-DD.
batchId YES This must be a unique number (preferably sequential) you must generate to identify this specific api call. Upon success, this number will be returned in the response.

Response

A successful response includes batchId, an added list of new users and an updated list of existing users that were updated. Each entry contains the user's id and available email and username. A missing username may be null or omitted. Either list is empty when no users were added or updated, respectively.

Examples

Example: Add 2 trainees and enroll in 3 courses, 1 which is required. 
POST https://api.mindflash.com/api/v2/user

{
  "users": [
    {
      "firstName": "Tom",
      "lastName": "Jones",
      "email": "tjones@yourorg.com"
    },
    {
      "firstName": "Rumple",
      "lastName": "Stilskin",
      "email": "rumple@yourorg.com"
    }
  ],
  "requiredCourseIds": [ 1234 ],
  "courseIds": [ 6789, 6543 ],
  "seriesIds": [],
  "groupIds": [],
  "clientDatestamp": "2013-07-17",
  "batchId" : 122
}
					
Response: 200
{
  "batchId": 122,
  "added": [
    { "id": 12345, "email": "tjones@yourorg.com", "username": null },
    { "id": 12346, "email": "rumple@yourorg.com", "username": null }
  ],
  "updated": []
}

When an existing user is matched by email or username, the response lists that user under updated instead:

Response: 200
{
  "batchId": 123,
  "added": [],
  "updated": [
    { "id": 12345, "email": "tjones@yourorg.com" }
  ]
}
