Error Responses

All public API requests require the x-mindflash-apikey request header. Errors are returned with an HTTP status code and a JSON body. The common error formats are:

HTTP Status Response body
400 Bad Request 
{
  "type": "bad_input",
  "message": "Bad input.",
  "param": "no_param",
  "code": "no_code"
}
401 Unauthorized 
{
  "type": "not_authorized",
  "message": "You are not authorized to perform that action.",
  "code": "no_code"
}
404 Not Found 
{
  "type": "resource_not_found",
  "message": "Resource not found.",
  "param": "no_param",
  "code": "no_code"
}
500 Internal Server Error 
{
  "type": "server_error",
  "message": "A server error has occurred."
}

API key validation errors

API-key availability failures are returned as HTTP 400 errors with type api_key_validation. The code identifies the failure: 

{
  "type": "api_key_validation",
  "message": "The Mindflash API is not available for your account.",
  "code": "api_not_available"
}
{
  "type": "api_key_validation",
  "message": "The Mindflash API is not available for your account.",
  "code": "account_inactive"
}
